# Enlangg NotebookLM Video Directory

Drop your NotebookLM generated `.mp4` video files here to power the video player on the **Learn** page (`learn.html`):

### File Naming Convention:
1. `01_hello_world.mp4` - Topic 01: First Program & The Sovereign Declaration
2. `02_memory_slots.mp4` - Topic 02: Deterministic Memory Slots & Inferred Types
3. `03_spoken_math.mp4` - Topic 03: Spoken Math & Arithmetic Operations
4. `04_logic_branching.mp4` - Topic 04: Decision Logic: Branching & Fallbacks
5. `05_loops_iteration.mp4` - Topic 05: Loops: While, Until & Bounded Iteration
6. `06_procedures.mp4` - Topic 06: Procedures, Scopes & Return Values
7. `07_data_structures.mp4` - Topic 07: Structured Data: Lists & Hash Maps
8. `08_python_god_call.mp4` - Topic 08: Python God Call & C-ABI Foreign Interop

### Alternatively:
If you prefer YouTube, Vimeo, Google Drive, or Loom video embeds, simply replace the `<video>` element with an `<iframe>` inside `learn.html`.
