PowerShell & CMD Install

Run this command in any standard PowerShell or CMD window. It fetches the latest binary, creates local directories, and automatically updates your shell PATH.

PowerShell (Run as User)
powershell -ExecutionPolicy ByPass -c "irm https://enlangg.vercel.app/install.ps1 | iex"
Command Prompt (CMD)
curl -fsSL https://enlangg.vercel.app/install.cmd -o install.cmd && install.cmd

macOS (Apple Silicon & Intel)

Enlangg compiles native universal binaries for macOS 12+ (Monterey, Ventura, Sonoma, Sequoia) supporting Apple Silicon (M1/M2/M3/M4, arm64) and Intel x86_64 processors.

Terminal (zsh / bash)
curl -fsSL https://enlangg.vercel.app/install.sh | bash

This script automatically installs the binaries into ~/.enlangg/bin and adds the export path to your ~/.zshrc and ~/.bash_profile. Requires standard Xcode Command Line Tools (xcode-select --install).

Docker Container Deployment

Deploy Enlangg microservices in reproducible, minimal container environments using Alpine Linux:

Dockerfile
FROM alpine:latest # Install lightweight C build toolchain RUN apk add --no-cache gcc musl-dev curl bash # Install Enlangg Sovereign Toolchain RUN curl -fsSL https://enlangg.vercel.app/install.sh | bash ENV PATH="/root/.enlangg/bin:${PATH}" WORKDIR /app COPY . /app # Compile and run service RUN enlng compile server.enlngs -o /app/service EXPOSE 8080 CMD ["/app/service"]

Frequently Asked Questions & Troubleshooting

Windows SmartScreen says "Windows protected your PC"?

Click "More info" and then click "Run anyway". As an independent open-source project without a multi-thousand-dollar corporate code signing certificate, Enlangg Studio binaries are 100% clean, virus-free, and verifiable on GitHub.

Terminal says "'enlng' is not recognized as an internal command"?

If you installed via the setup wizard or PowerShell script, simply restart your Command Prompt or PowerShell window so your operating system reloads its refreshed system PATH environment variables.

Can I use Enlangg Studio completely offline?

Yes! Enlangg Studio bundles all 7 C99 compilers locally inside the app. You do not need an Internet connection, Node.js, or Python to code, run, or build.

What if my corporate firewall blocks the direct download?

Use our official GitHub CDN Mirror link directly on this page. It serves through GitHub's global infrastructure with HTTPS and cross-origin acceleration.
