🎓 Progressive Curriculum

Learn Enlangg from Fundamentals to Systems

A step-by-step masterclass designed for developers, educators, and language enthusiasts. Progress from the Hello World milestone to full-stack domain development.

Lesson 01 Estimated: 5 mins

Your First Enlangg Program: The Sovereign Declaration

Every Enlangg source file begins with an explicit type header that instructs the compiler which grammar engine to invoke. For general computational logic, we use type enlng.

lesson01_hello.enlng
type enlng // Printing to standard output display "Hello, Sovereign World!" display "Welcome to the zero-symbol English programming ecosystem."
Run this in Playground ↗
Lesson 02 Estimated: 8 mins

Spoken Variables & Arithmetic Operations

Forget cryptic operators like *, /, or %. Enlangg uses the exact spoken English phrases for calculations:

lesson02_math.enlng
type enlng create apples of 15 create friends of 3 create apples_per_friend of apples divided by friends create remainder of apples modulo friends display "Each friend receives:" display apples_per_friend display "Remaining in basket:" display remainder
Lesson 03 Estimated: 10 mins

Branching Sentences: If, Otherwise If, and Otherwise

In Enlangg, conditional structures use natural conversational logic clauses:

lesson03_conditions.enlng
type enlng create user_age of 21 create has_id of 1 if user_age is greater than or equal to 18 and has_id is equal to 1: display "Access granted: Verified adult citizen." otherwise: display "Access denied: Verification threshold not satisfied."
Lesson 04 Estimated: 12 mins

Iterative Execution: While Loops & State Evolution

Enlangg loops use while <condition>: syntax with clean 4-space indentation. Variables evolve through deterministic slot assignment:

lesson04_loop.enlng
type enlng create limit of 10 create sum of 0 create i of 1 while i is less than or equal to limit: create sum of sum plus i create i of i plus 1 display "Sum of integers from 1 to 10 is:" display sum
Lesson 05 Estimated: 15 mins

Full-Stack Unification: Connecting .enlngf and .enlngs

Build a complete client-server application without writing a single line of HTML or CSS:

app.enlngf
type enlngf create title of "Sovereign Analytics Portal" create heading of "Real-Time Transaction Feed" create button of "Refresh Telemetry" on click button: call server endpoint "/api/telemetry"
