Standard Library & The Python God Call

Explore built-in zero-overhead modules for arithmetic, string manipulation, cryptosystems, and native zero-serialization Python interoperability.

math.sqrt(number) std.math

Computes the IEEE-754 double precision square root of a non-negative number using optimized CPU SIMD instructions.

create root of call math.sqrt with 144 // Result: 12.0
string.reverse(text) std.string

Reverses an arbitrary UTF-8 encoded string in-place with zero heap allocations, preserving grapheme cluster boundaries.

create reversed of call string.reverse with "racecar"
crypto.sha256(data) std.crypto

Generates an authentic NIST FIPS 180-4 256-bit cryptographic digest formatted as a lowercase 64-character hexadecimal string.

create digest of call crypto.sha256 with "sovereign"
file.read_all(path) std.io

Reads the entire contents of a filesystem file into an inferred memory buffer using memory-mapped I/O (mmap).

create contents of call file.read_all with "config.enlng"

The God Call: Zero-Overhead Python Bridge

Traditional multi-language bridges rely on slow inter-process communication (IPC), JSON serialization, or sockets that introduce massive latency overhead (15-50ms per call). Enlangg implements The God Call: a direct C-ABI binding that shares the active process virtual memory table with CPython.
