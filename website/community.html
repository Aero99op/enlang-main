Community, Contributing & Roadmap

What is done, what is next, and how to help. Enlangg is a small open-source project; the code and the issue tracker are on GitHub.

Roadmap

What has shipped, and what is planned. Planned items have no date.

Shipped: Language Core

Completed

English-syntax grammar, lexer and parser with friendly error messages, a built-in interpreter (5.5.1) and a C backend that builds executables with gcc.

Shipped: Six File Types and Seven Tools

Completed

Separate tools for .enlng, .enlngf, .enlngs, .enlngd, .enlngm and .enlngdb, plus the enlangg front door that dispatches to them.

Shipped: Installers

Released

Windows installer (enlangg-setup.exe), Linux and macOS installer (enlangg-install.sh), Enlangg Studio for Windows, and a 202-page PDF manual.

Planned

Not started

Python and C interop from Enlangg code, APK/IPA packaging for .enlngm, preview windows on Linux and macOS, and faster execution for heavy loops.

Who Maintains This

Enlangg is maintained by a single developer, with contributions welcome through GitHub issues and pull requests. There are no formal working groups or steering committee.

Developer Contribution Guide

Want to contribute to the compiler or standard library? The toolchain is plain C and builds with make:

Local Compiler Setup & Test Suite Execution
# 1. Clone repository git clone https://github.com/Aero99op/enlang-main.git cd enlang-main # 2. Build the tools with gcc and make make # 3. Check that the interpreter and the C path agree python tests/test_interp_parity.py

Proposing a Change

For anything that changes the grammar or the standard library, please start with an issue:

  1. Open an issue: describe the problem and show example Enlangg code.
  2. Discuss: agree on the grammar and how errors should read.
  3. Send a pull request: include a test program; CI runs it through both the interpreter and the C path.
