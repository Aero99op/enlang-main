Contributing to Enlangg

We welcome language engineers, documentation authors, and runtime developers. Because Enlangg upholds strict sovereignty standards, all contributions must respect the following core axioms:

The Three Sovereign Rules of Contribution
  1. Zero Cryptic Symbols: Never introduce operators or syntax requiring non-English symbols (e.g., &&, ||, !=). All grammar must remain natural English phrases.
  2. Zero Runtime Dependencies: Core runtime and compiler must compile cleanly with any ANSI C99+ compiler without external third-party libraries.
  3. Deterministic Performance: All core algorithms must satisfy strict execution limits with zero runtime garbage collection pauses.

The RFC (Request for Comments) Lifecycle

Architectural modifications, syntax additions, or standard library extensions must be proposed via an official RFC document specifying grammar BNF, compilation semantics, and memory footprints.
