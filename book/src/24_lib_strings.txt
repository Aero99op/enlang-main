# The Standard Library: lib_strings

`lib_strings.enlng` fills the gaps left by the built-in text functions: trimming, case conversion, padding, searching by position, and formatting. Import it at the top of a program:

::: src
use "lib_strings.enlng"
:::

Positions count from zero everywhere in this module. A "range" is written as a start position and an end position, where the end is not included (so `0, 5` is the first five characters), except where the table says it is a start and a count.

## Measuring and testing

| Function | Gives |
|---|---|
| `string_length(text)` | The number of characters. |
| `string_contains(text, piece)` | True when `piece` is somewhere in `text`. |
| `string_starts_with(text, prefix)` | True when the text begins with `prefix`. |
| `string_ends_with(text, suffix)` | True when it ends with `suffix`. |
| `string_index_of(text, piece)` | The position of the first match, or -1. |
| `string_count_char(text, ch)` | How many times one character appears. |
| `count_occurrences(text, piece)` | How many times a piece appears. |
| `is_palindrome(text)` | True when the text reads the same backwards. |

::: code
type enlng
use "lib_strings.enlng"

show string_length("hello")
show string_contains("hello", "ell")
show string_starts_with("hello", "he") string_ends_with("hello", "lo")
show string_index_of("hello", "l")
show string_index_of("hello", "z")
show string_count_char("banana", "a")
show count_occurrences("banana", "an")
show is_palindrome("level") is_palindrome("hello")
:::

## Taking pieces

| Function | Gives |
|---|---|
| `char_at(text, position)` | One character. |
| `sub_string(text, start, end)` | The characters from `start` up to but not including `end`. |
| `string_substring(text, start, end)` | The same. |
| `string_slice(text, start, count)` | `count` characters starting at `start`. |
| `string_split(text, separator)` | The same as the built-in `split`. |
| `string_join(list, separator)` | The same as the built-in `join`. |

::: code
type enlng
use "lib_strings.enlng"

remember s as "hello world"
show char_at(s, 1)
show sub_string(s, 0, 5)
show string_substring(s, 6, 11)
show string_slice(s, 6, 5)
:::

This is the answer to "there is no slicing syntax": `sub_string` does the job in one call.

## Trimming

| Function | Gives |
|---|---|
| `trim(text)` | The text without spaces at both ends. |
| `trim_left(text)`, `trim_right(text)` | Without spaces at one end. |
| `strip_prefix(text, prefix)` | Without `prefix` if it begins the text. |
| `strip_suffix(text, suffix)` | Without `suffix` if it ends the text. |

::: code
type enlng
use "lib_strings.enlng"

show "[" + trim("   padded   ") + "]"
show "[" + trim_left("   padded") + "]"
show "[" + trim_right("padded   ") + "]"
show strip_prefix("unhappy", "un")
show strip_suffix("report.txt", ".txt")
:::

## Case

| Function | Gives |
|---|---|
| `to_upper(text)`, `to_lower(text)` | All capitals, all small letters. |
| `capitalize(text)` | The first letter in capitals, the rest as it was. |
| `title_case(text)` | Each word starting with a capital. |
| `to_snake_case(text)` | `words_joined_by_underscores`. |
| `to_kebab_case(text)` | `words-joined-by-hyphens`. |
| `to_camel_case(text)` | `wordsJoinedWithCapitals`. |
| `char_to_upper(ch)`, `char_to_lower(ch)` | Case of one character. |

::: code
type enlng
use "lib_strings.enlng"

show to_upper("Hello") to_lower("Hello")
show capitalize("hello world")
show title_case("hello big world")
show to_snake_case("Hello Big World")
show to_kebab_case("Hello Big World")
show to_camel_case("hello big world")
:::

## Padding and repeating

`pad_left` and `pad_right` make text a fixed width, which is how you line up columns:

::: code
type enlng
use "lib_strings.enlng"

show repeat_char("ab", 3)
show pad_left("7", 3, "0")
show pad_right("7", 3, ".")
show "Item " + pad_right("tea", 8, ".") + pad_left("25", 5, " ")
show "Item " + pad_right("coffee", 8, ".") + pad_left("120", 5, " ")
:::

## Replacing

| Function | Gives |
|---|---|
| `string_replace_first(text, target, replacement)` | The text with the first `target` replaced. |
| `string_replace_all(text, target, replacement)` | The text with every `target` replaced. |

::: code
type enlng
use "lib_strings.enlng"

show string_replace_first("a-b-c", "-", "+")
show string_replace_all("a-b-c", "-", "+")
show string_replace_all("one  two", "  ", " ")
:::

## Filling in a template

`string_format_1`, `string_format_2` and `string_format_3` fill numbered holes `{0}`, `{1}` and `{2}` in a template:

::: code
type enlng
use "lib_strings.enlng"

show string_format_1("Hello, {0}!", "Asha")
show string_format_2("{0} + {1} = 3", 1, 2)
show string_format_3("{2} {1} {0}", "a", "b", "c")
:::

A hole written `{}` without a number is not filled in.

### Replacing at the ends of a string

These functions, and `string_replace_all`, are built on the built-in `split`. In 5.5.0 `split` left out empty pieces, and a replacement at the very start or end of the text, or two in a row, was lost. From 5.5.1 `split` keeps them and all of these come out right:

::: code
type enlng
use "lib_strings.enlng"

show string_replace_all("a-b-c", "-", "+")
show string_replace_all("-a-", "-", "+")
show string_replace_all("a--b", "-", "+")
show string_format_2("{0} + {1}", 1, 2)
show string_format_2("x {0} y {1}", 1, 2)
:::

`string_replace_first` never used `split` and was not affected.

## Small helpers for output

`banner(title)` makes a heading line and `csv_row` joins three or four columns with commas:

::: code
type enlng
use "lib_strings.enlng"

show banner("Report")
show csv_row("name", "age", "city")
show csv_row_4("a", "b", "c", "d")
:::

## rot13 and slugs

`rot13` swaps each letter with the one thirteen places along, so applying it twice gives back the original. It is a toy cipher and is not secret in any real sense. `slugify` is another name for `to_kebab_case`; it keeps punctuation, so clean the text first if you need a web-safe slug.

::: code
type enlng
use "lib_strings.enlng"

show rot13("Hello")
show rot13(rot13("Hello"))
show slugify("Hello World Again")
:::

## Predictable names for the built-in helpers

The module also defines `string_arrange(text, positions)`, a function version of the `arrange` statement that does work as a function, and wrappers for the position-based built-ins. Use the functions in this chapter when you want to work with words; the built-ins `string_add`, `string_insert` and `string_replace` (chapter 8) work by position.

::: code
type enlng
use "lib_strings.enlng"

show string_arrange("abcdef", [5, 4, 3])
:::
