# Built-in Function Reference

These functions are part of the language and need no `use` line. They are the same ones the interpreter and the C backend both provide. Everything else in the standard library is ordinary Enlangg code that you import.

## Numbers

| Call | Gives |
|---|---|
| `sqrt(x)` | The square root. |
| `pow(x, y)` | `x` raised to the power `y`. |
| `abs(x)` | The absolute value. |
| `floor(x)` | The largest whole number not above `x`. |
| `ceil(x)` | The smallest whole number not below `x`. |
| `round(x)` | `x` rounded to the nearest whole number. |
| `min(a, b)` | The smaller of two numbers. |
| `max(a, b)` | The larger of two numbers. |
| `random_number(low, high)` | A random whole number from `low` to `high`, both included. |

## Text

| Call | Gives |
|---|---|
| `len(text)` | The number of characters. |
| `to_number(text)` | The number the text spells: `to_number("42")` is 42, `to_number("3.5")` is 3.5. Text that is not a number is an error. |
| `to_text(value)` | The value as text, the way `show` prints it. |
| `split(text, separator)` | A list of the pieces. With `""` as separator, one piece per character. |
| `join(list, separator)` | The text items of the list glued together with the separator. |
| `contains(text, piece)` | True if `piece` appears in `text`. Also works on lists. |
| `reverse(text)` | The text backwards. |
| `string_set_at(text, position, character)` | The text with the character at `position` replaced. |
| `string_remove_at(text, position)` | The text without the character at `position`. |
| `string_remove(text, piece)` | The text with the first `piece` taken out. |

`string_add`, `string_insert` and `string_replace` also exist. They take the text, then the piece, then a position (chapter 8). To replace a word rather than a position, the standard library module `lib_strings.enlng` has `string_replace_first`, `string_replace_all`, and others.

## Lists

| Call | Gives |
|---|---|
| `len(list)` | The number of items. |
| `append(list, value)` | Adds `value` at the end. |
| `pop(list)` | Removes the last item and gives it back; `null` if the list is empty. |
| `contains(list, value)` | True if the value is in the list. |
| `reverse(list)` | A reversed copy. |
| `join(list, separator)` | See above. |

## Maps

| Call | Gives |
|---|---|
| `keys(map)` | A list of the keys. |
| `values(map)` | A list of the values. |
| `has_key(map, key)` | True if the key is present. |
| `len(map)` | The number of entries. |

## Files, time and the machine

| Call | Gives |
|---|---|
| `read_file(path)` | The file as text; empty text if it cannot be read. |
| `write_file(path, text)` | Writes the file, replacing it. |
| `append_file(path, text)` | Adds to the end of a file. |
| `file_exists(path)` | True or false. |
| `time_now()` | Seconds since 1970. |
| `sleep(seconds)` | Waits. |

## More built-ins (5.5.2)

| Call | Gives |
|---|---|
| `arguments()` | The words typed after the file name: `enlng run app.enlng one two` gives `["one", "two"]`. |
| `env("NAME")` | The environment variable, or `null` if it is not set. |
| `type_of(x)` | `"number"`, `"decimal"`, `"text"`, `"list"`, `"map"`, `"true/false"`, `"function"` or `"null"`. |
| `char_code(text)` | The number of the first character (Unicode): `char_code("A")` is 65. |
| `char_of(number)` | The character with that number: `char_of(65)` is `"A"`. |
| `unique(list)` | A new list with each value once, in the order first seen. |
| `insert_at(list, position, value)` | Puts `value` before `position`; a negative position counts from the end. |
| `remove_at(list, position)` | Removes the item and gives it back. |
| `remove_key(map, key)` | Removes the key; true if it was there. |
| `check(condition, message)` | Does nothing when the condition is true; otherwise an error "Check failed: message". |
| `time_ms()` | A clock in milliseconds, for timing a piece of code. |

## JSON

| Call | Gives |
|---|---|
| `to_json(value)` | The value as JSON text. Maps, lists, text, numbers, true/false and null can be written; a function cannot. |
| `to_json_pretty(value)` | The same, spread over indented lines. |
| `from_json(text)` | The map, list or value the JSON describes. Invalid JSON is an error that says where. |

## Patterns (regular expressions)

A pattern is written in text, so a backslash is doubled: `"\\d+"` means one or more digits. Supported: `.` `[abc]` `[^a-z]` `\\d` `\\w` `\\s` (and `\\D` `\\W` `\\S`) `\\b` `^` `$` `( )` `(?: )` `|` `*` `+` `?` `{2,3}`, lazy forms such as `*?`, and `(?i)` at the start to ignore capitals.

| Call | Gives |
|---|---|
| `regex_match(pattern, text)` | True if the pattern is found anywhere in the text. |
| `regex_find(pattern, text)` | The first match, or `null`. |
| `regex_find_all(pattern, text)` | A list of all matches. |
| `regex_groups(pattern, text)` | The whole match followed by what each `( )` matched, or `null`. |
| `regex_replace(pattern, text, with)` | Every match replaced. In `with`, `$1` to `$9` are the groups and `$$` is a dollar sign. |
| `regex_split(pattern, text)` | The pieces between matches. |

## Dates and times

| Call | Gives |
|---|---|
| `make_time({"year": 2026, "month": 11, "day": 1, "hour": 9})` | Seconds since 1970 for that local date; missing parts are 0 (month and day 1). |
| `date_parts(seconds)` | A map with `year`, `month`, `day`, `hour`, `minute`, `second`, `weekday` and `day_of_year`. |
| `format_time(seconds, pattern)` | The time as text, with `%Y` `%m` `%d` `%H` `%M` `%S` `%A` `%B` and the other C patterns. |

## Folders and other programs

| Call | Gives |
|---|---|
| `is_folder(path)` | True if the path is a folder. |
| `list_folder(path)` | The names inside, sorted. A missing folder is an error. |
| `make_folder(path)` | Makes the folder and any missing ones above it. |
| `delete_file(path)` | Deletes a file or an empty folder; true if it worked. |
| `rename_file(from, to)` | Renames or moves; true if it worked. |
| `run_command(command)` | Runs the command and gives `{"code": 0, "output": "..."}`; the output holds everything it printed. |
| `http_get(url)` | `{"status": 200, "body": "..."}`. An address that cannot be reached is an error; a 404 is not, check `status`. |
| `http_post(url, body)` | The same, sending the body. A map or list is sent as JSON, anything else as text. |

`http_get` and `http_post` use the `curl` program, which comes with Windows 10 and later, macOS and most Linux systems. They need an address that starts with `http://` or `https://`.

## Phrases that act like functions

Some summaries are written as phrases instead of calls:

| Phrase | Gives |
|---|---|
| `count of x` | The number of items or characters. |
| `length of x` | The same. |
| `sum of list` | The total of a list of numbers. |
| `average of list` (or `avg of list`) | The mean. |
| `max of list`, `min of list` | The largest and smallest item. |
| `first of list`, `last of list` | The ends of the list. |
| `item at position` | One item. |
| `key of map` | One entry. |

## A sampler

::: code
type enlng

remember xs as [5, 3, 9]
remember m as {"k": 1}

show sqrt(81)
show pow(3, 4)
show abs(-2)
show floor(2.9) ceil(2.1) round(2.5)
show min(4, 6) max(4, 6)
show len("abc") len(xs) len(m)
show split("a-b-c", "-")
show join(["x", "y"], "/")
show contains("seashell", "shell")
show contains(xs, 9)
show reverse("abc")
append(xs, 1)
show pop(xs)
show keys(m) values(m) has_key(m, "k")
show count of xs sum of xs max of xs first of xs
:::

## Where each function lives

Every function listed here is available in both ways of running a program. If a name you expected is missing, such as `upper`, `trim` or `replace`, it is not a built-in; look in `lib_strings.enlng` and `lib_std.enlng`, which are covered in the next part.
